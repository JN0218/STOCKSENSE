# STOCKSENSE
# 📦 StockSense - 스마트 재고 운영 시스템

> 사람과 AI가 함께하는 재고 관리 플랫폼  
> 사무실과 현장을 연결하고, 재고 상태를 자동 판정해 운영 의사결정을 지원합니다.

---

## 🛠 기술 스택

| 분류 | 기술 |
|------|------|
| Backend | Java |
| Database | Oracle 21c |
| Frontend | HTML |

---

## 👤 담당 역할 - 사원관리 (Employee CRUD)

- 사원 목록 조회
- 사원 등록 (이름, 부서, 생년월일, 연락처, 프로필 이미지)
- 사원 정보 수정
- 사원 삭제
- 사원 ID/비밀번호 기반 로그인 연동
